Dina Zayed — Assignment 3: Portfolio Website with API Integration

HOW TO RUN
Open index.html in a modern browser. For reliable testing, use a local server:
  python -m http.server 8000
Then visit http://localhost:8000

WHAT WAS ADDED
- Dedicated Projects section
- Live Cairo weather using the Open-Meteo REST API
- JavaScript fetch() with async/await
- Loading, error, refresh, and success states
- Dynamic DOM updates (temperature, condition, weather icon, observed time)
- Responsive styles and navigation links

All original Assignment 2 content and interactive features are preserved.

API
https://open-meteo.com/en/docs
No API key required for non-commercial use.

DEPLOY
1. Create a GitHub repository and upload the files inside this folder (not just the ZIP).
2. Settings > Pages > Deploy from a branch > main / root > Save.
3. Once the site is live, paste the published URL into link.txt.
4. ZIP all the files including link.txt and submit the ZIP.

NOTE
Contact form performs client-side validation only. It does not send email.
